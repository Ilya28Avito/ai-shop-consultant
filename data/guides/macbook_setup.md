\# Руководство по настройке MacBook



\## Первый запуск

1\. Откройте крышку — MacBook включится автоматически

2\. Выберите язык (Русский) и регион (Россия)

3\. Подключитесь к Wi-Fi

4\. Войдите в Apple ID или создайте новый



\## Настройка Touch ID

1\. Следуйте инструкциям при первом запуске

2\. Приложите палец к кнопке питания несколько раз

3\. Установите резервный пароль

4\. Touch ID используется для разблокировки и покупок



\## Перенос данных с Windows

1\. Скачайте приложение "Ассистент миграции" (уже установлено)

2\. На Windows установите Windows Migration Assistant

3\. Запустите на обоих устройствах и следуйте инструкциям

4\. Выберите данные для переноса (документы, фото, настройки)



\## Основные сочетания клавиш

\- \*\*Cmd + C/V/X\*\*: копировать/вставить/вырезать

\- \*\*Cmd + Z\*\*: отменить действие

\- \*\*Cmd + Space\*\*: открыть Spotlight (поиск)

\- \*\*Cmd + Tab\*\*: переключение между приложениями

\- \*\*Cmd + Q\*\*: закрыть приложение



\## Настройка для работы в России

1\. Установите Яндекс Браузер или используйте Safari

2\. Добавьте карту МИР в Apple Wallet

3\. Установите Госуслуги, Сбербанк Онлайн, ВТБ Онлайн

4\. Настройте VPN при необходимости



\## Обслуживание MacBook

\- Очищайте вентиляционные отверстия от пыли

\- Калибруйте аккумулятор раз в месяц

\- Обновляйте macOS через Системные настройки

\- Делайте резервные копии через Time Machine
